Phân tích dữ liệu thương mại điện tử Olist

2023 • Bài tập nhóm học phần Kho dữ liệu và kinh doanh thông minh

• Bộ dữ liệu: https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce
• Đóng góp của bản thân: Exploratory Data Analysis (EDA)
Bước 1: Khảo sát
- Tìm hiểu mô hình, quy trình cho bài toán: Tổng quan lĩnh vực, quy trình nghiệp vụ, luồng dữ liệu, ERD
- Tìm hiểu yêu cầu phân tích: Mô tả theo các chủ điểm và minh họa thông qua mindmap
- Tìm hiểu hệ thống chỉ số, cây phân tích dashboard và liên kết dashboard sẽ phân tích ở đâu trên quy trình/mô hình
- Tìm hiểu data flow of IT systems, quy mô dữ liệu và tần suất cập nhật dữ liệu mới
Bước 2: ERD OLTP
👉Màu sắc phân loại, gạch chân các trường quan trọng để xây dựng data model đa chiều
Bước 3: Data exploration
- Sử dụng đa dạng biểu đồ để xác định phân phối, thống kê đăc trưng và phân tích tương quan
- Phân tích chi tiết kiến trúc dữ liệu
Bước 4: ETL dữ liệu
- Sử dụng đa dạng công cụ ETL: Power query - Python - SQL
- Mô tả quá trình OLAP và trình bày Before - After của hoạt động ETL
Bước 5: Phân tích Dimension
- Tiền xử lý dữ liệu để tạo ra các chiều mới hiêu quả hơn để phân tích khi dữ liệu quá dài
- Phân dimension thành các nhóm cho dễ theo dõi và thống kê số lượng dòng ở mỗi dimension
Bước 6: Phân tích Data model OLAP (logic, vật lý)
Bước 7: Xây dựng Dashboard
- Phân tích chi tiết dạng story telling
- Phân tích OLAP (sử dụng slicer, drill down,...). có
- Phân tích theo dòng thời gian để phát hiện tính mùa, xu thế, dự báo
- Public dashboard lên web
• Công việc: Phân tích Dim, Fact, OLTP, OLAP
